## 🛠️ Como Usar (Exclusivo para Google Earth)

> ⚠️ **Nota:** Este mini-portal utiliza recursos visuais avançados (HTML/CSS) suportados nativamente pelo **Google Earth**. Ele não renderiza o design visual no *Google My Maps*.

### No Celular (Android / iOS)
1. Baixe o arquivo [`Lo Gatito Browser.kml`](https://github.com/alxtreme1/Lo-Gatito-Browser/releases/download/stable/Lo.Gatito.Browser.kml).
2. Abra o aplicativo **Google Earth**.
3. Abra o menu lateral, acesse **Projetos** e toque em **Open / Abrir** (ou **Importar arquivo KML**).
4. Selecione o arquivo baixado e toque no marcador **LO GATITO** para abrir o painel.

### No Computador (Google Earth Web ou Pro)
1. Acesse [earth.google.com](https://earth.google.com/) ou abra o Google Earth Pro.
2. Vá em **Projetos** > **Importar arquivo KML do computador**.
3. Clique no ponto no mapa para abrir a caixa com os atalhos.
